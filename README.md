## 데이터

| 파일 | 내용 |
|---|---|
| `scores_2026.csv` | 성적 원본, 114행 · 5열 (학번, 이름, 반, 과목, 점수), UTF-8 |
| `scores_2026_cp949.csv` | 같은 내용, 인코딩만 cp949 → `pd.read_csv(..., encoding="cp949")` |
| `mini.csv` | 10행 — 손으로 풀어 보는 검증용 |

**진단 결과 (원본)**: 점수 빈 칸 6개, 완전 중복 행 4개, 반 값 3종류(`'1반 '` 공백), 과목 값 4종류(`'프로그래밍 '` 공백), 점수 범위 −5 ~ 999.

**정제 규칙** (`analysis.py`의 `정제(df)`):

1. 점수가 비어 있는 행은 삭제한다. → 114 → 108
2. 모든 열이 완전히 같은 행은 하나만 남긴다. → 108 → 104
3. 반과 과목의 앞뒤 공백을 제거한다.
4. 점수가 0~100 밖인 행은 삭제한다 (999 세 개, 음수 하나). → 104 → 100

**정제 후**: 100행, 반 = 1반 · 2반, 과목 = 수학 · 영어 · 프로그래밍.

| 반 | 개수 | 평균 | 중앙값 | 최댓값 |
|---|---|---|---|---|
| 1반 | 50 | 78.24 | 78.0 | 98.0 |
| 2반 | 50 | 71.44 | 71.0 | 98.0 |

## 검증 (`test_analysis.py`)

1. 행 수 보존 — 정제하면 100행, 반은 두 종류만 남는다.
2. 합계 일치 — 반별 합계의 합(7484.0) = 전체 합계(7484.0).
3. 손계산 대조 — `mini.csv` 정제 후 1반 평균 = (90+70+80+80)/4 = 80.0.
4. 스팟 체크 — 1반 수학 8개 값의 합 480 ÷ 8 = 60.0, groupby 결과와 같음.
